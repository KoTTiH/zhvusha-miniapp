# Проверяемые сценарии pet-проекта

Этот документ фиксирует поведение, связанное с контрактными проверками. Он не является отчётом о готовности к коммерческому запуску или сравнением точности с другими приложениями.

## Ввод и главная

Новый пользователь видит первый food CTA, ведущий к записи еды. Виджеты не появляются скрытым дефолтом: пользователь включает их сам. Контракт — `pnpm widgets:check`.

Недавние записи поддерживают удаление и отмену. Сценарий проверяет `pnpm smoke:smart-history`. Разбор целого дня и предупреждение о примерном результате фиксирует `pnpm day-voice:check`.

## Расчёт и AI-кредиты

Источник расчёта, уверенность AI и основание порции должны оставаться видимыми при записи и правках. Контракт — `pnpm nutrition:check`.

Первичный разбор стоит один внутренний AI-кредит, уточнение результата бесплатно, непригодный результат возвращает списанный кредит. Правила закрепляет `pnpm ai-credit:check`; они описывают внутренний баланс, а не стоимость API провайдера.

## AI и данные

Пользователь отправляет текст, голос и фото. Советник автоматически дополняет запрос недавними записями дневника, историей диалога и подтверждённой памятью. Сырые фотографии разбора еды не попадают в журнал AI-анализов; фотографии советника сохраняются отдельно по согласию. Контракты — `pnpm ai-privacy:check` и `pnpm assistant:check`.

## Где хранятся данные

Панель называет активный режим хранения и не раскрывает внутренние пользовательские ключи. Контракт — `pnpm storage-status:check`.

## Экспорт данных

JSON включает дневник и настройки. В интерфейсе видны последний экспорт, fingerprint и код копии.

Восстановление из JSON показывает превью состава до записи. Данные объединяются с существующими; «Целостность данных» проверяет ссылки между записями и справочниками. Контракт — `pnpm data-export:check`; browser-smoke — `pnpm smoke:data-export`.

## Паспорт готовности

Локальная диагностика выполняет сверку export/import по коду без AI, сети и записи данных. Она не проверяет готовность внешних сервисов. Контракт — `pnpm app-readiness:check`.

## Карта проверок

Панель содержит справку по командам, включая browser-smoke, `pnpm bundle:check`, `pnpm accessibility:check` и `pnpm smoke:accessibility`. Она не запускает проверки и не показывает вымышленный успешный результат. Контракт — `pnpm quality-map:check`.

## Доступность

Диалоги удерживают фокус и возвращают его после закрытия; виджеты можно перевести в режим настройки с клавиатуры. Проверки: `pnpm accessibility:check` и `pnpm smoke:accessibility`.

## CI

Обязательная цепочка CI: `pnpm check`, `pnpm build`, `pnpm bundle:check`. Нормализация штрих-кодов проверяется без AI-запросов. Browser-smoke в CI остаются необязательными. Соответствие workflow, package scripts и pre-commit проверяет `pnpm quality-gate:check`.
